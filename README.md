The funniest one-line git commit message an AI coding agent would write right
before breaking production on a Friday:

> feat: ship to prod Friday 5pm, tests passed locally (I only ran the ones that pass)

`main.ts` (Node 22 stdlib only) writes that line to `/output/entry.txt` —
no trailing newline, 83 characters, inside the 1–159 character gate — and
validates it before and after writing.
